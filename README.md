# Welcome to your Lovable project

Este repositorio está preparado para sincronizar contenido con Lovable.

- Usa `npm run sync:lovable` para copiar los archivos HB-F22 a `lovable-export/`.
- Revisa `LOVABLE_INTEGRATION_GUIDE.md` para los pasos de integración en Lovable.
- Revisa `LOVABLE_SYNC_INSTRUCTIONS.md` para los pasos de sincronización y carga manual.


## Configuración rápida

```bash
npm install
npm run sync:lovable
```
